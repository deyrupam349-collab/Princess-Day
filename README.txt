# For My Love — ready-to-publish website

Your website is already built. The receiver is **My Love** and the sender is **Just Friend** throughout.

## Publish it on Vercel — beginner-friendly steps

You do not need to write code, install anything, or use Terminal.

### Step 1 — Unzip the website
1. Download `my-love-surprise-vercel.zip`.
2. On your computer, double-click the ZIP file to extract it.
3. Open the extracted `my-love-surprise` folder. You should see `index.html`, `style.css`, `script.js`, `README.txt`, and `WEBSITE_PROMPT.txt`.

### Step 2 — Upload the files to GitHub
1. Go to https://github.com/ and sign in (or create a free account).
2. Click the **+** button near the top-right, then choose **New repository**.
3. Name it `my-love-surprise`. Choose **Public** or **Private**, then click **Create repository**.
4. On the new repository page, click **Add file → Upload files**.
5. Open the extracted `my-love-surprise` folder on your computer. Select all five files inside it and drag them into the GitHub upload area. Upload the files themselves—not the ZIP file and not an extra enclosing folder.
6. Scroll down and click **Commit changes**.

### Step 3 — Publish through Vercel
1. Go to https://vercel.com/ and sign in using GitHub.
2. Click **Add New → Project**.
3. Find the `my-love-surprise` repository and click **Import**.
4. If Vercel asks for settings, use:
   - Framework Preset: **Other**
   - Root Directory: `./`
   - Build Command: leave empty
   - Output Directory: leave empty (if it requires a value, enter `.`)
5. Click **Deploy** and wait for it to finish.
6. Vercel will show your website URL. Open that URL on your phone to check it.
